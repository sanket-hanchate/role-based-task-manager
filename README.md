# 🚀 TaskFlow - Role-Based Task Management System

A full-stack Role-Based Task Management System built using the MERN Stack with secure JWT authentication, role-based access control, admin analytics, activity logs, and task management features.

# 📌 Features

## 🔐 Authentication & Authorization
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Role-Based Access Control (RBAC)

---

## 👤 User Features
- Create Tasks
- Update Task Status
- Delete Tasks
- View Personal Tasks

---

## 👨‍💼 Admin Features
- Admin Dashboard
- Analytics Overview
- Manage Users
- Activate/Deactivate Users
- Delete Users
- View Activity Logs
